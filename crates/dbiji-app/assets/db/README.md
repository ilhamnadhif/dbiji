Database logos, used to tell connections apart. The trademarks belong to their owners.

- PostgreSQL, SQLite, Microsoft SQL Server, ClickHouse, Redis and MongoDB:
  the coloured logos of [Devicon](https://devicon.dev) 2.16 (MIT,
  `Devicon-LICENSE.txt`), drawn in their own colours.
- MySQL, MariaDB, CockroachDB, Oracle, Apache Cassandra, Elasticsearch and
  Neo4j: [Simple Icons](https://simpleicons.org) 13.21 (CC0 1.0 Universal),
  one-colour shapes drawn in the brand's colour.
