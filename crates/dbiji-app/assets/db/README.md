Database logos, used to tell connections apart. The trademarks belong to their owners.

- PostgreSQL, SQLite, Microsoft SQL Server, ClickHouse and DuckDB: the
  coloured logos of [Devicon](https://devicon.dev) 2.16 (MIT,
  `Devicon-LICENSE.txt`), drawn in their own colours.
- MySQL, MariaDB, CockroachDB, MongoDB and Redis: [Simple Icons](https://simpleicons.org)
  (CC0 1.0 Universal), one-colour shapes drawn in the brand's colour.
